# Hero AMTI Instagram Flow

Asset: `public/hero.png` (1024 × 1536), diganti 29 Oktober 2026 menggunakan built-in imagegen.

Ilustrasi clay pastel menyatukan kamera, kartu feed Instagram, jembatan dan gedung dengan sensor monitoring. Lavender, mint dan peach mengikuti tema creative studio. Logo AMTI asli dirender oleh BrandLogo; teks tetap HTML, bukan bagian gambar. Hero tidak ditimpa ilustrasi SVG atau gradient gelap. Teks navy berada di panel glass transparan dengan blur 20px untuk menjaga keterbacaan di atas ilustrasi.

Judul hero memakai ukuran 24–30px dengan bobot medium dan deskripsi 14px. Judul memakai efek typing dengan ruang setinggi kalimat lengkap agar layout stabil. Screen reader menerima kalimat utuh. Slide berganti otomatis tanpa indikator titik atau tombol navigasi.

## Dark mode

Logo memakai varian otomatis sesuai tema. Dark mode menggunakan aset khusus `public/hero-dark.png` (1024 × 1536), dibuat dengan built-in imagegen.
