# Audit struktur dan keterbacaan — 20 Oktober 2026

> Arsip historis: mencatat kondisi dan keputusan pada tanggal dokumen. Bukan aturan atau panduan implementasi aktif; lihat [indeks dokumentasi](../../README.md).

## Cakupan dan temuan

Pemeriksaan lanjutan meninjau pemisahan tanggung jawab panel publikasi, form publikasi, editor, upload, daftar reporting, shared request/polling dan breadcrumb. Pemeriksaan backend terkait mencakup enqueue/worker publikasi, callback workflow dan auth. Ini catatan temuan konkret, bukan jaminan bahwa seluruh kemungkinan bug telah ditemukan.

- PublicationPanel sebelumnya menjalankan request, polling, aksi API dan pengelolaan Blob. Tanggung jawab ini dipindahkan ke usePublications; component menyusun UI dan modal penolakan.
- Error preview yang terlambat setelah unmount tidak lagi menghasilkan toast. Cleanup URL preview tidak menutup lightbox yang sudah menampilkan gambar milik component lain.
- Panel tanpa draft tidak mengirim request dengan draft ID yang tidak tersedia. Aksi yang selesai setelah unmount tidak menampilkan toast atau memanggil callback halaman.
- Breadcrumb URL editor kompatibilitas kini mempunyai link detail seperti route utama.
- Backend memisahkan pemilihan foto/desain publikasi dari orchestration enqueue. Transaksi tetap mengunci project/draft sampai snapshot tersimpan; guard revisi, idempotency dan cleanup tetap dipertahankan.

## Verifikasi

Tes regresi baru mencakup lifecycle preview dan breadcrumb editor. Suite backend tetap menguji alur publikasi, konflik transaksi dan callback. Lint, typecheck, test serta build dijalankan pada kedua repo. Pengujian ini tidak mengirim postingan Instagram atau menjalankan workflow n8n eksternal. Verifikasi visual browser belum dilakukan pada audit ini.
