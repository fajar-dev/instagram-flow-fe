# Audit dan refactor — 15 Oktober 2026

## Cakupan dan temuan

Audit meliputi perubahan manual pada auth/reset password, service API, tipe response, route guard, layout/branding, halaman CRUD, serta integrasi backend. Desain, aset logo/hero, template, dan alur resend tetap dipertahankan.

| Temuan | Tindakan |
| --- | --- |
| Login dan logo mengarah ke `/app`, padahal dashboard berada di `/` | Tujuan navigasi diperbaiki |
| Logout menaruh Authorization dalam body | Header dikirim di argumen config; state dan storage dibersihkan segera |
| Constructor singleton memakai Nuxt composable dan memulai request sebelum plugin siap | Inisialisasi melalui `app/plugins/api.client.ts`; service tidak mengakses konteks Nuxt |
| Client Axios baru untuk setiap akses dan refresh paralel | Satu instance dengan locale dinamis; request 401 bersamaan berbagi satu refresh; retry maksimal sekali |
| Error login publik memicu refresh/logout | Refresh hanya untuk request dengan header auth; logout dikecualikan |
| Gagal jaringan dianggap sesi tidak valid | Kegagalan jaringan/server saat refresh tidak menghapus sesi; credential ditolak tetap mengakhiri sesi |
| Refresh yang selesai setelah logout menghidupkan sesi kembali | Versi sesi mencegah penerapan response refresh yang kedaluwarsa |
| Service menampilkan toast dan membuang error asli | Service mempertahankan error asli; `useServiceError()` diinisialisasi di setup komponen dan menangani presentasi |
| ApiResponse duplikat/tidak memiliki meta dan import dari file yang salah | Kontrak tunggal di `app/types/api.d.ts`; hasil typecheck diperbaiki |
| Query email reset dirangkai manual | Axios params mengenkode email/token, termasuk alamat dengan `+` |
| Query route dipaksa menjadi string | Reset hanya menerima query string tunggal; array/missing ditolak |
| Judul/schema auth tidak reaktif terhadap locale | Judul dan schema auth memakai computed/callback; email divalidasi dengan Zod email |
| Footer copyright diduplikasi | Footer auth dipusatkan di layout dan i18n, tahun dinamis |
| Timer pencarian dan URL blob preview tidak dibersihkan | Cleanup pada unmount/pergantian preview; pencarian tidak memicu request ganda ketika halaman direset |
| SDK Google dipanggil tanpa client ID dan membuat render error | Pemanggilan SDK hanya saat konfigurasi tersedia; tombol Google tetap ada, nonaktif dengan pesan sementara tidak tersedia jika belum dikonfigurasi |
| Format menyimpang dari ESLint project | Auto-fix memakai aturan yang sudah ada; aturan tidak dilonggarkan untuk meloloskan lint |

## Keputusan arsitektur

- Page/component menangani event, toast, navigasi, loading, dan validasi UI. Composable menangani perilaku UI yang berulang.
- Service menangani transport/kontrak API dan sesi; jangan memanggil useToast, useI18n, useRuntimeConfig, atau navigasi di constructor/service.
- Plugin Nuxt menjadi composition root untuk config, locale, HTTP client, dan invalidasi sesi.
- Capture composable saat setup, sebelum await. Handler async menangani error pada boundary UI; tidak menelan kegagalan di service atau mengganti error asli dengan Error kosong.
- Gunakan satu ApiResponse generik dan unknown untuk error. State auth diekspos readonly.
- Interface/class tambahan dibuat jika memisahkan tanggung jawab konkret; tidak diwajibkan untuk helper murni.

## Google login

Fitur Google dipertahankan. `GOOGLE_CLIENT_ID` harus diisi pada environment frontend dan sesuai OAuth client backend. SDK hanya dapat diinisialisasi setelah client ID tersedia. Perbaikan `.env.example` menghapus quote yang tidak ditutup. Konfigurasi credential tidak dibuat atau ditebak oleh agent. Setelah mengganti environment, restart Nuxt; OAuth Google perlu smoke test dengan akun dan origin yang terdaftar.

## Pengujian

- `bun run test`: regresi service HTTP/sesi menggunakan adapter Axios, tanpa login nyata atau server eksternal.
- `bun run typecheck` dan `bun run lint`: kontrak TypeScript/Vue dan aturan lint.
- `bun run build`: build Nuxt; unduhan font Geist membutuhkan akses jaringan saat cache belum ada.
- Browser: periksa login, tombol Google saat konfigurasi kosong, navigasi forgot password, dan penolakan link reset tanpa query.

Baseline audit: 5 error typecheck; lint 394 error dan 14 warning. Test service baru mencakup refresh bersamaan, login invalid, jaringan offline, refresh ditolak, header logout, encoding email, dan refresh terlambat setelah logout.

## Batas

Penyimpanan JWT di localStorage dipertahankan; migrasi ke cookie HttpOnly membutuhkan perubahan kontrak backend dan CSRF. Reset/revoke semua sesi belum disediakan backend. Pengiriman email, upload MinIO nyata, dan login OAuth Google nyata belum diverifikasi. Build masih dapat memperingatkan ukuran chunk vendor; pemisahan bundle lebih lanjut harus berdasarkan pengukuran, bukan memecah secara acak.

Hasil akhir: 7 test service lolos (0 gagal), typecheck dan lint bersih, build produksi berhasil. Browser memverifikasi login, tombol Google yang tetap terlihat saat client ID kosong, halaman forgot password, dan redirect link reset tanpa token.
